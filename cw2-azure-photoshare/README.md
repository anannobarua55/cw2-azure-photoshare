# CW2 Azure PhotoShare

A simple runnable React/Vite homepage for the COM769 Coursework 2 Azure PhotoShare project.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```text
http://localhost:5173
```

## Build for Azure Static Web Apps

```bash
npm run build
```

The production build is created in:

```text
dist
```

## Suggested Azure Static Web Apps settings

- App location: `/`
- API location: leave blank for now
- Output location: `dist`
